# Salon Trač – aplikacija A.1

Aplikacija za rezervaciju termina u salonu lepote „Trač“.

Projekat se realizuje prema varijanti arhitekture C.

## Članice tima

- Tamara Jerotijevic
- Jovana Dumic

## Tehnologije

- React
- TypeScript
- ASP.NET Core Web API
- .NET Worker Service
- PostgreSQL
- Redis
- RabbitMQ

## Delovi aplikacije

- React frontend aplikacija
- ASP.NET Core Web API
- Pozadinski proces za obradu novih rezervacija
- PostgreSQL baza podataka
- Redis keš
- RabbitMQ message queue

## Status projekta

Projekat je u fazi postavljanja početne strukture.
